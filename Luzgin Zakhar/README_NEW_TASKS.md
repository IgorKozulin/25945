### Задачи 6 и 7

Для проверки таймера запустите программу, **не вводите ничего 5 секунд**: содержимое файла должно появиться целиком. В Task 6 поиск реализован через `open/read/lseek/close`, а в Task 7 — через `mmap` и `munmap`, без `read/lseek` для файла.

### Задача 9

`Task_9/task9 --no-wait Task_9/long.txt` — первая часть (родитель не ждёт). Без `--no-wait` родитель ждёт через `waitpid()`, его последняя строка гарантированно следует после вывода `cat`.

### Задача 17

Интерактивное редактирование ASCII-строк: Backspace удаляет символ; Ctrl+U удаляет всю текущую строку; Ctrl+W — последнее слово; Enter фиксирует строку; Ctrl+D в начале строки завершает. Перенос длинных слов через границу 40 колонок. Терминал поддерживает ANSI escape-последовательности (Terminal macOS, VS Code Terminal, SSH).

### Задача 21

Запуск только из интерактивного терминала. Для SIGINT используйте Ctrl+C, для SIGQUIT — Ctrl+\\. Программа выводит число звуковых сигналов при завершении.

### Задачи 30, 31, 32: Unix domain sockets

**Откройте два (или три) терминала** внутри одного Solaris сервера. Пример для Task 31:

Терминал 1:
```sh
./Task_31/server /tmp/luzgin_task31.sock
```
Терминал 2:
```sh
./Task_31/client /tmp/luzgin_task31.sock 'HeLLo, FiRsT!'
```
Терминал 3:
```sh
./Task_31/client /tmp/luzgin_task31.sock 'seCoNd CliEnt!'
```
Сервер выводит текст в верхнем регистре. Task 30 обслуживает одного клиента и завершается. Task 31 — несколько клиентов через `poll`. Task 32 — несколько клиентов с **асинхронными сокетами и сигналом SIGIO/FASYNC** без `poll/select`. Для задач 30 и 32 замените `31` в командах на `30` и `32`.

**Особенно важно для Solaris:** Task 32 реализован через `fcntl(FASYNC)`, `SIGIO` и неблокирующий `read`, как описывается в руководстве по asynchronous socket I/O в Solaris. До сдачи обязательно проверьте его на вашем сервере illumos; конкретная поддержка и поведение сигналов зависят от окружения.
