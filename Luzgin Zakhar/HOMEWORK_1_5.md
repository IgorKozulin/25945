```sh
./Task_1/task1 -d -p -i -u -c

printf '1\n3\n0\n' | ./Task_5/task5 Task_5/sample.txt
```

**Task 1:** `ulimit(UL_GETFSIZE)` выдаёт ограничение на размер файла в блоках по 512 байт. `-C` принимает размер core-файла в байтах. Попытка поднять предел выше hard limit может завершиться ошибкой ОС. Одноимённые опции обрабатываются справа налево.

**Task 2:** в Калифорнии в зимний сезон действует PST (UTC−8), в летний — PDT (UTC−7). Использована строка TZ с актуальными правилами перехода для США; пример «20:00 UTC → 12:00 PST» соответствует зимнему времени. Файл ex_time.c из задания не предоставлен, поэтому создан самостоятельный эквивалент.

**Task 3:** в каталоге Task_3 выполнить `sh prepare.sh`: он создаёт локальный `private_data.txt` с правами 600. Этот файл намеренно не добавляется в Git. Для проверки эффекта setuid нужен **другой пользователь** из той же группы и подходящие права на каталог/бинарный файл; при запуске только от владельца UID до и после совпадут. Для демонстрации с другим пользователем в безопасном учебном каталоге: `chmod 750 task3`, затем по условиям преподавателя `chmod u+s task3`; повторно запустить от другого пользователя. Не устанавливайте владельцем бинарника root. Возможна блокировка setuid на файловой системе, смонтированной с nosuid.

**Task 4:** завершение ввода, когда в начале строки стоит точка. Строки выводятся в порядке ввода. Для реализации списка не используются STL/`std::string`.

**Task 5:** первая строка имеет номер 1. Номер 0 завершает программу. В таблицу включены пустые строки и последняя строка, даже если в конце файла нет символа перевода строки.
