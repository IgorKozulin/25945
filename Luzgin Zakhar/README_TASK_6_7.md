# Операционные системы — задания 6 и 7

Программы на C для Solaris (SunOS/illumos) и других POSIX-систем.

## Задание 6: таблица строк + alarm

Программа строит таблицу смещений и длин строк текстового файла через `open`, `read`, `lseek`, `close`. Пользователь выбирает номер строки (нумерация с 1). Для каждого ввода отводится 5 секунд (`alarm(5)` и `SIGALRM`). Если время истекает, печатается **весь файл**, затем программа завершается. `0` — выход.

Компиляция и запуск из папки `Luzgin Zakhar`:

```sh
make -C Task_6
./Task_6/task6 Task_6/sample.txt
```

## Задание 7: память mmap + alarm

Та же логика поиска строк и 5-секундного таймера, но содержимое файла отображается в память с помощью `mmap`, а поиск осуществляется через прямой доступ к байтам памяти. Для чтения *текстового файла* не применяются `read` и `lseek`. Файл отображается только на чтение (`PROT_READ`, `MAP_PRIVATE`). Пустые файлы обрабатываются отдельно (для них `mmap` не вызывается). `0` — выход.

```sh
make -C Task_7
./Task_7/task7 Task_7/sample.txt
```

## Проверки

* Введите `2` и Enter — программа выведет вторую строку.
* Введите `3` и Enter — пустая третья строка.
* Введите `0` и Enter — программа завершится.
* Запустите заново и **ничего не вводите 5 секунд** — выведется всё содержимое файла.

Компилированные программы не хранятся в Git: `.gitignore` игнорирует исполняемые файлы.

**Примечание:** исходники подготовлены и проверены на Linux; отдельно проверьте работу и компиляцию на учебном Solaris, куда у вас уже есть доступ через SSH.
